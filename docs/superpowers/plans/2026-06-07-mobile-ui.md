# liby 모바일 UI 개선 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 폰에서 노트 전체보기(`read.html`)와 메인 앱(`base.html`)을 읽고 탐색하기 편하게 만든다. 데스크톱(`md+`)은 현행 유지.

**Architecture:** 순수 Tailwind 반응형 클래스(`md:` 분기)와 소량의 바닐라 JS만 사용. `read.html`은 viewport 메타 추가 + 콘텐츠 순서 재배치, `base.html`은 사이드바를 모바일 오프캔버스 드로어로, `note_detail_modal.html`은 패딩 미세 조정.

**Tech Stack:** FastAPI + Jinja2 + HTMX + Tailwind(CDN). 테스트: pytest + httpx ASGITransport (기존 `tests/test_routes_read.py`, `tests/test_routes_partials.py`, `tests/test_routes_items.py` 패턴 재사용).

```javascript
function toggleSidebar() {
  const sb = document.getElementById('sidebar');
  const ov = document.getElementById('sidebar-overlay');
  if (!sb || !ov) return;
  const opening = sb.classList.contains('-translate-x-full');
  sb.classList.toggle('-translate-x-full', !opening);
  ov.classList.toggle('hidden', !opening);
}
function closeSidebar() {
  const sb = document.getElementById('sidebar');
  const ov = document.getElementById('sidebar-overlay');
  if (!sb || !ov) return;
  sb.classList.add('-translate-x-full');
  ov.classList.add('hidden');
}
function toggleTheme() {
  const html = document.documentElement;
  const btn = document.getElementById("theme-btn");
```

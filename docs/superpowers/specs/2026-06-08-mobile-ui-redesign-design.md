# liby 모바일 UI 재설계 (와이어프레임 재검토)

## 배경 / 문제

직전 작업(`docs/superpowers/specs/2026-06-07-mobile-ui-design.md`)으로 shell(base.html 햄버거 드로어, read.html 순서 재배치, 모달 패딩)은 개선했으나, **실제 콘텐츠인 노트 카드(`note_card.html`)가 데스크톱 가로 레이아웃 그대로**라 모바일에서 정리 상태가 엉망이다.

390px 폭 Playwright 캡처로 확인된 문제:

1. **노트 카드 짜부라짐** — 카드가 `flex`로 [타입뱃지][클릭영역(제목·요약·태그)][우측 컨트롤 컬럼(프로젝트선택·상세정리·.md열기·🗑)] 가로 배치. 모바일에서 우측 컨트롤 컬럼(`max-w-[110px]` 셀렉트 등)이 폭을 먹어 제목이 2~3글자마다 줄바꿈, "빠른 정리" 뱃지가 세로로 짜부라짐.
2. **네비 탭 스크롤바 노출** — 입력 타입 탭(YouTube/PDF/Code/Text/Markdown)에 `overflow-x-auto`가 걸려 모바일에서 보기 싫은 가로 스크롤바 + 탭 잘림.
3. **상단 입력영역 면적 과점** — 큰 URL 입력창 + 5개 탭 + 프로젝트 선택바가 화면 위쪽을 크게 차지해, 정작 콘텐츠(노트 목록) 우선순위가 낮다.
4. **추천 노트 그리드** — `#recommended-notes`가 `grid grid-cols-2`라 모바일에서 카드 2개가 나란히 붙어 짜부라짐.

## 사용 맥락 / 방향

- 분석 트리거는 주로 Discord로 한다. 폰 웹(메인 앱)은 **주로 열람/탐색** 용도(사용자 확인). 관리 액션(프로젝트 지정·상세정리·삭제)은 가끔.
- 선택한 접근: **[1] 열람우선 + 입력접기** — 상단 입력영역을 `+ 분석` 토글로 접어 화면을 비우고 노트 카드에 집중, 카드는 세로화(컨트롤은 상세 모달로).
- 데스크톱(`md+`) 레이아웃은 전부 현행 유지. 순수 Tailwind 반응형 클래스 + 소량 JS.

## 변경 (4개 surface)

### A) `note_card.html` — 모바일에서 컨트롤 컬럼 숨김

우측 컨트롤 컬럼 `<div class="flex flex-col gap-1 flex-shrink-0">`에 `hidden md:flex` 부여.
- 모바일: 컨트롤이 사라져 클릭영역(`flex-1`)이 전체 폭 차지 → 제목 짜부라짐 해소. 카드 탭 → 상세 모달(기존 `hx-get .../detail`).
- 데스크톱: 컨트롤 컬럼 현행대로 노출.

```
[모바일]                                  [데스크톱 — 현행 유지]
┌──────────────────────────────┐      ┌────────────────────────────┐
│ [YOUTUBE] AG 시대의 교육: 스탠 │      │[YT] 제목…          [미분류▼] │
│           포드 폴 교수가 말하는 │      │     날짜·정리모드    [상세정리]│
│ 2026-06-07·Claude-cli·빠른정리 │      │     요약…           [.md열기] │
│ 스탠포드 폴김 교수는 '입시'에…  │      │     #태그            [ 🗑 ]  │
│ #교육철학 #SMILE #메타AI  $0.00│      └────────────────────────────┘
└──────────────────────────────┘
```

### B) `note_detail_modal.html` — 모바일 관리 경로 보강

카드 컨트롤이 모바일에서 사라지므로, 가끔 하는 관리를 모달에서 가능하게 한다. 현재 모달엔 삭제(🗑)·전체화면(📖)만 있음. 헤더 아래에 **액션 행** 추가:
- **프로젝트 지정 셀렉트** — `hx-post /api/items/{id}/project`, 변경 시 적용. (카드의 셀렉트와 동일 엔드포인트)
- **상세 정리 버튼** — `summary_mode == 'quick'`일 때만. `hx-post /api/items/{id}/upgrade`, `#queue-panel`에 append. (카드 버튼과 동일 동작)
- `.md 열기`는 서버(=PC)에서 .md 파일을 여는 동작이라 폰에서 무의미 → 모달에 추가하지 않음.
- 이 액션 행은 데스크톱에서도 노출(모달은 양 플랫폼 공용). 기능 중복이 아니라, 모달을 통한 관리는 데스크톱에서도 자연스러움.

```
┌──────────────────────────────┐
│ [YOUTUBE] 제목…       🗑 📖 ✕ │
│ [프로젝트 ▼]  [상세 정리]      │ ← 신규 액션 행
│ ── 영상/요약/본문 …            │
└──────────────────────────────┘
```

### C) `base.html` — 상단 입력영역 접기 + 네비 탭 데스크톱 전용

- **입력 타입 탭** 컨테이너(`<div class="flex items-stretch overflow-x-auto">`)에 `hidden md:flex` 부여 → 모바일에서 탭/스크롤바 제거, 데스크톱 현행.
  - `overflow-x-auto`는 데스크톱에선 거의 안 쓰이나 유지(좁은 데스크톱 창 대비). 모바일에선 컨테이너 자체가 숨겨지므로 스크롤바 비노출.
- **`+ 분석` 토글 버튼** 네비바에 추가(`id="analysis-toggle"`, `md:hidden`). 입력 래퍼 표시 토글.
- **입력 래퍼**: `#input-panel` + 프로젝트 선택바를 하나의 래퍼(`id="analysis-panel"`)로 감싸고 `hidden md:block` 부여 → 모바일 기본 숨김, 데스크톱 항상 표시. `+ 분석`이 모바일에서 `hidden` 토글.
  - 모바일에서 펼친 입력은 기본 YouTube 입력(이미 `#input-panel`에 로드됨) + 프로젝트바. 타입 전환은 데스크톱 전용(비목표).
- **JS**: `toggleAnalysis()` — `#analysis-panel`의 `hidden` 클래스 토글(드로어 토글과 동일 패턴, null 가드).
- 검색바(index.html)는 변경 없음 — 모바일에서도 항상 노출(열람 핵심).

```
[모바일 — 접힘(기본)]              [모바일 — + 분석 펼침]
┌──────────────────────────┐    ┌──────────────────────────┐
│ ☰  liby      [+ 분석] 🌙 │    │ ☰  liby      [+ 분석] 🌙 │
├──────────────────────────┤    ├──────────────────────────┤
│ 최근 업데이트  🔍 검색…   │    │ [YouTube URL 입력…]       │
│ ┌ 노트 카드 ┐            │    │ 현재 프로젝트 ▼           │
└──────────────────────────┘    ├──────────────────────────┤
                                 │ 최근 업데이트  🔍 검색…   │
                                 └──────────────────────────┘
```

### D) `index.html` — 추천 노트 그리드 모바일 1열

`#recommended-notes`의 `grid grid-cols-2` → `grid grid-cols-1 md:grid-cols-2`.

## 테스트 / 검증

### 자동 (기존 `test_routes_*` 문자열 검사 패턴)

- `note_card.html`(detail 아님, `/api/items` 목록 또는 `/` 렌더): 컨트롤 컬럼에 `hidden md:flex` 포함.
- `note_detail_modal.html`(`/api/items/{id}/detail`): 프로젝트 지정 셀렉트(`/api/items/{id}/project`)와 상세정리 버튼(`/api/items/{id}/upgrade`, quick 노트에서) 노출.
- `base.html`(`/`): `id="analysis-toggle"`, `id="analysis-panel"`, 입력 래퍼 `hidden md:block`, 탭 컨테이너 `hidden md:flex`, `function toggleAnalysis` 포함.
- `index.html`(`/`): 추천 그리드 `grid-cols-1 md:grid-cols-2` 포함.
- 전체 스위트 유지(현재 255 → 신규 테스트 추가분).

### 수동 (Playwright 모바일 390폭 + 실기기)

1. `/` 모바일 캡처: 카드 제목이 전체 폭 사용(짜부라짐 없음), 컨트롤 컬럼 비노출, 네비 스크롤바 없음, 입력영역 접힘.
2. `+ 분석` 탭 → 입력 + 프로젝트바 펼침/접힘.
3. 카드 탭 → 모달에서 프로젝트 지정·상세정리 가능.
4. 추천 노트 1열.
5. 데스크톱 폭: 카드 컨트롤·입력영역·탭 모두 현행 그대로.
